Color Computer ROMs
===================

BMCoco needs the ROMs of the machine it emulates. They are copyrighted by
Tandy and Microsoft, so they are not included: copy your own ROM images
into this folder. XRoar finds them by file name:

  CoCo 1/2 (the default)   bas13.rom      Color BASIC 1.3
                           extbas11.rom   Extended Color BASIC 1.1
  Disks (RS-DOS)           disk11.rom     Disk Extended Color BASIC 1.1
                                          (or disk10.rom)
  CoCo 3                   coco3.rom      Super Extended Color BASIC
  MC-10                    mc10.rom

Older versions also work: bas10.rom - bas12.rom, extbas10.rom. Dragon
ROMs (d32.rom, d64_1.rom, d64_2.rom, ddos12a.rom) work too, and the
Prologica CP-400's: cp400bas.rom and cp400ext.rom (or cp400extbas.rom, as
the Color Computer Archive's XRoar/CP400 folder has it).

For hard disks (the IDE interface): hdblba.rom (HDB-DOS) or yados.rom.
For the Becker port (DriveWire): hdbdw3bck.rom.

BMCoco starts the first CoCo it has ROMs for: a CoCo 2 (NTSC), then a CoCo 3.
Choose another in the menu (F12, Machine), or with machine= in cmdline.txt.

All the CoCo ROMs can be downloaded from the Color Computer Archive, already
named this way:

  https://colorcomputerarchive.com/repo/ROMs/XRoar/CoCo/

Copy the files from both its BASIC_OS folder (Color BASIC, Extended BASIC,
CoCo 3) and its DOS folder (Disk BASIC) into this folder.
